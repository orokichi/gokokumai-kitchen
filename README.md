# 五穀の食卓 — 五穀米のたのしみ方

五穀米をおいしく楽しむための、日本語ワンページサイトです。炊き方のポイントと、梅しそおむすび・きのこバター醤油丼・焼き鮭のだし茶漬けを紹介します。CSSの湯気・器・浮遊モチーフと、レシピ切り替え・作る数の操作を備えています。
